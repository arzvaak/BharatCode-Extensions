# BharatCode Extensions

[English](README.md) | 中文

![BharatCode Harness](assets/bharatcode-cover.svg)

面向 [BharatCode Harness](https://github.com/arzvaak/BharatCode-Harness) 的扩展与入门技能，为研究、文档、图形和编程提供工具，也可围绕自己的项目构建工作流。

[了解 BharatCode](https://arzvaak.github.io/BharatCode-Harness/) · [应用下载](https://github.com/arzvaak/BharatCode-Harness/releases) · [扩展发布](https://github.com/arzvaak/BharatCode-Extensions/releases)

## 内置扩展

应用内置 BharatCode Providers、Context、Task Board、Library、Code Tools、Skills、Research、Story Continuity、Visuals、Usage 及扩展商店。核心扩展随桌面应用打包。订阅适配器另行随应用分发，需要对应的提供方账户。

## 安装扩展与技能

从应用侧栏打开 **Extensions** 或 **Skills**。安装前检查要求。签名目录、精确归档校验和及平台验证决定可用性。可选候选用于发现，在打包和工作流检查通过前保持不可用。

公开发布提供签名目录、已验证扩展归档及托管运行时，下载无需 GitHub 账户。仓库保持公开，因为已安装构建使用这些发布 URL；私有源码仓库也可以通过独立公开产物渠道分发。

入门技能位于 `skills/`。在 Skills 侧栏添加此仓库、查看技能并安装。标准 `SKILL.md` 格式也兼容其他工具。

## 应用更新

从 [BharatCode 应用发布](https://github.com/arzvaak/BharatCode-Harness/releases)获取 Linux RPM、DEB 或 AppImage。当前应用构建可在应用程序菜单内检查更新。旧版更新文件保留于此以兼容已安装构建。Windows、ARM64 及依赖真实账户的推理不在已验证 Linux 预览范围内。
