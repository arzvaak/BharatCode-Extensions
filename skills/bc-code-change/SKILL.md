---
name: bc-code-change
description: "Implement a scoped code change with repository guidance and appropriate verification."
---

Inspect the repository instructions and current changes before editing. Identify the behavior to change and its acceptance criteria. Preserve unrelated work. Implement the smallest coherent change, use the available language-server and review tools, and run checks appropriate to its impact. Report actual results, remaining failures, and the files changed. Publishing and deployment follow the user's authorization.
