---
name: bc-document-workflow
description: "Create or revise a common document with inspectable output and discovered dependencies."
---

Identify the requested document format and existing source. Reuse available document tools and discover converters only when the requested output needs them. Preserve the editable source, inspect the resulting document and its layout where relevant, and report its location. Explain a missing dependency or unverified conversion accurately; do not install heavy runtimes or download models without user configuration.
